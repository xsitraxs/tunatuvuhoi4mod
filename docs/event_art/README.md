# Иллюстрации Тайшетской кампании

`irkutsk_source.png` и `taishet_source.png` — оригинальные AI-сгенерированные
иллюстрации альтернативной истории, стилизованные под чёрно-белую съёмку 1930-х.
Это не архивные фотографии и не ручная работа. Сторонние игровые картинки
в новые DDS не копировались. Названные люди на изображениях не изображаются.

В игре используются только файлы `gfx/event_pictures/tt_tuva/`:

| DDS | Размер | Использование |
| --- | --- | --- |
| irkutsk.dds | 210×176 | обычное окно: Иркутск и рейд |
| negotiations.dds | 210×176 | обычные дипломатические окна |
| treaty_news.dds | 397×153 | газетное окно итогового договора |

DDS подготовлены ImageMagick, grayscale, DXT1, центральное кадрирование
с сохранением пропорций. Привязки — `interface/tt_tuva_event_pictures.gfx`.
Размеры DDS проверены по заголовкам; расположение в настоящем окне HOI4
ещё требует проверки. Исходники не нужны игре, `docs/**` исключён из экспорта.
